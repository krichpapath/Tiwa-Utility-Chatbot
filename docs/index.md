# Tiwa developer guide

Start with [setup](setup.md), then read the [architecture map](architecture.md).
The current project has one runtime implementation. Older serial-pipeline and branch
comparison notes are preserved in Git history, not maintained as alternative instructions.

## Work on a feature

- [Music and search](music.md): request interpretation, candidate review, queue execution.
- [Voice](voice.md): local activation, per-speaker capture, transcription, recovery.
- [Calendar](calendar.md): proposals, requester approval, Google writes.
- [Memory](memory.md): retrieval, extraction, persistence and evidence.
- [Dashboard](dashboard.md): settings, recordings and memory browsing.

## Work on the repository

- [Development](development.md): conventions, change boundaries and Git workflow.
- [Testing](testing.md): offline suite, targeted checks and live verification.
- [Configuration](configuration.md): files, providers and important settings.
- [Operations](operations.md): launch, troubleshooting and current limits.
